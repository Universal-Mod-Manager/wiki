---
title: Skyrim Mod Installation
description: Install and manage Skyrim mods with UMM.
---

Use this page when you want to install Skyrim mods in UMM.

## Prerequisites

- Skyrim Special Edition / Anniversary Edition installed.
- The game launched at least once.
- Mods downloaded from a trusted source (for example Nexus Mods).

## 1. Install Universal Mod Manager

1. Download the latest release of Universal Mod Manager.
2. Run the installer.
3. Launch Universal Mod Manager.

## 2. Configure the game and paths

1. Click the **gear icon** to open settings.
2. Select the game (**Skyrim Special Edition**).
3. Set the game path to the correct Skyrim installation folder.
4. Set the mods path to `../skyrim-se`.
5. For Skyrim, mods are then stored in the `../skyrim-se/mod` folder.

## 3. Get mods from Nexus Mods

1. Go to **Nexus Mods** and open the Skyrim mod page.
2. Download the mod with **Mod Manager Download** or **Manual Download**.
3. Import the archive into UMM if needed.

## 4. Add and manage mods

1. Click **Add Mod** or **Install from File**.
2. Select the mod archive.
3. Enable or disable the mod.
4. Change priority with **drag & drop** or by editing the **priority number**.
5. Click **Deploy / Apply** if needed.
