---
title: Installing a Mod from Nexus Mods
description: How to install a mod from Nexus Mods with UMM.
---

Use this page to install a mod from **Nexus Mods** with UMM.

## 1. Find the mod

1. Open the Nexus Mods page for the game.
2. Read the mod description, requirements, and compatibility notes.
3. Make sure the mod matches your game version.

## 2. Download the mod

1. Click **Files** on the mod page.
2. Choose the file you want.
3. Use **Mod Manager Download** when available.
4. If needed, use **Manual Download** instead.

## 3. Import it into UMM

1. Open UMM.
2. Click **Add Mod** or **Install from File**.
3. Select the archive you downloaded.
4. Wait for the import to finish.

## 4. Enable and deploy

1. Enable the mod.
2. Change its priority with **drag & drop** or by editing the **priority number**.
3. Click **Deploy / Apply** if UMM asks for it.

## 5. Verify in game

1. Launch the game from UMM.
2. Load a test save.
3. Confirm the mod works correctly.
