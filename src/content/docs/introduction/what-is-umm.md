**UMM (Universal Mod Manager)** is a mod management tool that lets you handle your game mods from one interface instead of doing manual file copy/paste.

It helps you:

- import mod archives (`.zip`, `.7z`, `.rar`),
- enable or disable each mod,
- reorder mod priority with drag & drop or priority numbers,
- apply/deploy changes safely,
- launch the game directly with your selected setup.

For Skyrim, UMM keeps your setup cleaner, reduces conflicts, and avoids common mistakes from manual installation.
