This guide explains the core workflow for **Universal Mod Manager**: install the app, select a game, import mods, manage priority, and launch the game.

## Prerequisites

- The target game installed.
- The game launched at least once.
- Mods downloaded from a trusted source (for example Nexus Mods).

## 1. Install Universal Mod Manager

1. Download the latest release of Universal Mod Manager.
2. Run the installer.
3. Launch Universal Mod Manager.

## 2. Configure the game and paths

1. Click the **gear icon** to open settings.
2. Select the game you want to manage.
3. Set the correct game path.
4. Set the mods path for that game.
5. Use the folder structure required by your setup, for example `../skyrim-se` for Skyrim or `/witcher3/` for The Witcher III.

## 3. Get mods from Nexus Mods

1. Open the mod page on **Nexus Mods**.
2. Download the mod with **Mod Manager Download** or **Manual Download**.
3. Import the archive into UMM if needed.

## 4. Add and manage mods

1. Click **Add Mod** or **Install from File**.
2. Select the mod archive (`.zip`, `.7z`, `.rar`).
3. Enable or disable the mod.
4. Change priority with **drag & drop** or by editing the **priority number**.
5. Click **Deploy / Apply** if needed.

## 5. Launch and verify

1. Launch the game from UMM.
2. Load a test save.
3. Confirm the mod is active.

## Quick troubleshooting

- **Mod does not appear in game**: check that it is enabled and deployed.
- **Crash after installing a mod**: disable the last added mod and test again.
- **Conflicts between mods**: review priority and load order.
- **Manager cannot find the game**: verify the game path in settings.
