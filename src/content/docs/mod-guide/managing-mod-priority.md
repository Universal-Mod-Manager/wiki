---
title: Managing Mod Priority
description: How to set load order and priority for mods in UMM.
siderbar:
  order: 2
---

In UMM, mod priority controls which mod wins when files conflict.

1. Use **drag & drop** in the mod list to reorder mods.
2. Or edit the **priority number** directly.
3. Keep gameplay-critical mods in a consistent order.
4. After changes, click **Deploy / Apply**.
